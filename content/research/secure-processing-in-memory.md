## Research focus

This research examines secure processing-in-memory systems and multi-party computation techniques, including arithmetic secret sharing and garbled circuits, for computation on untrusted hardware.

## Security and performance

The work analyzes off-chip data exposure, integrity risks, and CPU bottlenecks in secure-computing protocols. It considers how moving parts of secure workloads closer to memory changes both the attack surface and overall system performance.

## Early directions

Current ideas explore workload partitioning and precomputation strategies for UPMEM-style accelerators, with the goal of reducing host-CPU overhead while preserving the security properties of the underlying protocol.
